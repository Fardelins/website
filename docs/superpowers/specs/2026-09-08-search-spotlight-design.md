# Search Spotlight Design

The dashboard search trigger uses a brand-purple surface, border, icon treatment, and shortcut badge so it reads as an active product control rather than a grey wireframe.

When a search has no matches, the complete results canvas becomes a search scene. A faint grid spans the canvas, tightly packed Fardelins letterforms sit beneath it, and a large ASCII Fardelins wordmark is revealed by a soft flashlight that follows the pointer. A flashlight cursor reinforces the interaction. Before pointer input, the light drifts slowly; touch devices retain the drift, and reduced-motion users receive a static partial reveal.

Guidance and recovery actions sit directly on the scene without an opaque card obscuring the effect.
