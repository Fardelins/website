# Settings Rebuild

The settings area uses five non-sticky sections in this order: Profile, My Addresses, Appearance, Security, and Verification. The surface stays restrained at rest, with brand colour reserved for selection, focus, and hover feedback. Unsolicited live labels and flashing status dots are removed.

Profile changes are staged locally. Text edits and a cropped avatar activate the single Save Changes action in the section header. Saving submits the profile fields and staged avatar together as one user action. Email verification is shown inside the email field, with a resend action only when verification is still required.

My Addresses stores an uncapped, account-scoped list of reusable locations. Each address includes a label, street address, state, and city. Saved locations can be selected while entering either pickup or drop-off details in the parcel flow. The list is persisted per signed-in account on the current device because the current API collection marks the former customer property endpoints unavailable.

Security keeps only the password form and its Update Password header action. Appearance retains the existing controls with taller previews. Verification becomes a one-time identity-check flow: choose an accepted document, upload it, and then show the submitted review state instead of treating it as a general document library.

All interactive states remain keyboard accessible, responsive, and compatible with reduced motion.
